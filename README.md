# Книжная летопись

Семейный читательский дневник. В нём хранятся все книги, которые прочитали мама и Александра: обложка, автор, страницы, дата, понравилось или нет, заметка и голосовой рассказ «о чём эта книжка». Есть таймер «5 минут = 1 бусинка» для школьного задания.

Приложение работает в браузере телефона, его можно поставить на главный экран как обычное приложение. Без интернета оно тоже открывается.

## Как добавить книгу

1. Нажать большой **+** внизу.
2. **Сканировать штрихкод** на обороте книги (тот, что начинается на 978 или 979). Название, автор, страницы и обложка найдутся сами.
3. Если книга не нашлась: найти по названию, ввести ISBN вручную или заполнить всё самим.
4. **Обложка обязательна.** Выберите найденную картинку или нажмите «Сфотографировать».
5. Выберите, кто читал, поставьте смайлик, напишите заметку. По желанию запишите голосом рассказ (до 3 минут).

Каталоги для поиска: Немецкая национальная библиотека (DNB), Google Books, Open Library.

## Где хранятся данные

Данные лежат в двух местах:

| Где | Что | Зачем |
|---|---|---|
| Телефон (браузер) | всё | быстро и без интернета |
| **Ваш Google Drive** | таблица «Книжная летопись» + папки «Обложки» и «Голос» | на годы: телефон сменится, а данные останутся |

В репозитории на GitHub лежит **только код**. Ваших книг, фото и записей там нет.

Ещё есть кнопка «Хранилище → Копия-файл → Скачать»: один .json-файл со всем, включая картинки и голос.

## Подключить Google Drive (один раз, ~5 минут)

1. Откройте [sheets.new](https://sheets.new). Получится новая Google Таблица, назовите её «Книжная летопись».
2. В таблице откройте меню **Расширения → Apps Script**.
3. Удалите весь код в редакторе. Вставьте содержимое файла [`apps-script/Code.gs`](apps-script/Code.gs) и нажмите 💾 (сохранить).
4. Вверху выберите функцию **setup** и нажмите **Выполнить**.
   - Google попросит доступ, нажмите «Разрешить».
   - Если появится «Приложение не проверено»: **Дополнительные настройки → Перейти на страницу проекта (небезопасно)**. Это ваш собственный скрипт, он работает только в вашем аккаунте.
5. Нажмите **Начать развёртывание → Новое развёртывание**. Шестерёнка → **Веб-приложение**.
   - Запуск от имени: **Я**
   - У кого есть доступ: **Все** (без этого телефон не сможет отправлять данные; чужие без ключа ничего не прочитают и не запишут)
   - Нажмите «Начать развёртывание» и скопируйте **URL веб-приложения** (заканчивается на `/exec`).
6. В таблице появился лист **«Настройки»**. В ячейке B1 лежит **ключ доступа**.
7. В приложении: **Хранилище** → вставьте URL и ключ → **Сохранить и проверить**.

Готово. Каждая новая книга сама уходит в таблицу. Если интернета нет, она уйдёт позже.

**Новый телефон:** откройте приложение, вставьте тот же URL и ключ, нажмите **Восстановить**.

**Если меняете код скрипта:** Развёртывание → Управление развёртываниями → карандаш → Версия: «Новая версия». Адрес останется прежним.

## Как поставить на телефон

Откройте адрес приложения (GitHub Pages):

- **Android / Chrome:** меню ⋮ → «Добавить на главный экран» / «Установить приложение».
- **iPhone / Safari:** кнопка «Поделиться» → «На экран „Домой“».

Камере и микрофону нужно разрешение. Браузер спросит один раз.

## Для разработки

Обычные HTML, CSS и JavaScript без сборки. Запуск на компьютере:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

| Файл | Что делает |
|---|---|
| `index.html`, `styles.css` | каркас и оформление |
| `js/app.js` | экраны: полка, добавление, карточка, таймер, летопись, хранилище |
| `js/db.js` | хранилище в телефоне (IndexedDB) |
| `js/lookup.js` | поиск книги по ISBN и названию, обложки |
| `js/scanner.js` | сканер штрихкода (BarcodeDetector или ZXing) |
| `js/sync.js` | отправка в Google Drive и восстановление |
| `apps-script/Code.gs` | скрипт для Google Таблицы |
| `sw.js` | офлайн-режим. **После изменения файлов увеличьте `VERSION`** |
| `vendor/` | библиотека ZXing (Apache-2.0) |
| `fonts/` | шрифты Nunito и Caveat (SIL OFL) |
